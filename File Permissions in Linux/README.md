# File Permissions in Linux

## Project Overview

This project demonstrates the use of Linux command-line utilities to examine, interpret, and modify file and directory permissions in a secure computing environment. The objective was to verify existing permissions, identify unauthorized access, and apply the principle of least privilege by updating file and directory permissions using Linux commands.

## Scenario

As a security professional supporting a research team, I was responsible for reviewing file system permissions to ensure that only authorized users had access to sensitive files and directories. The project involved examining current permissions, removing unnecessary write access, securing hidden files, and restricting access to confidential directories.

## Objectives

* Examine file and directory permissions using Linux commands.
* Interpret Linux permission strings.
* Modify file permissions with `chmod`.
* Secure hidden files by assigning appropriate permissions.
* Restrict directory access to authorized users.
* Apply the Principle of Least Privilege to improve system security.
